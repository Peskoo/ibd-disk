Basé sur [IBD Disk, AbbVie](https://www.abbviepro.com/fr/fr/immunologie/gastro-enterologie/outils-et-services/ibd-disk.html)
IBD Disk, un outil pour évaluer l’impact de la maladie dans la vie de tous les jours

# Pré requis
- [docker](https://docs.docker.com/engine/install/)
- [docker compose](https://docs.docker.com/compose/)
# Comment installer l'outil
```bash
git clone
docker compose up --detach --build
http://<ip or localhost>:3000.
```
